# Reproduction guide and evidence log

The source of record is the supplied [11-page paper](../BeyondWaveform.pdf), arXiv:2606.05678v1. The [specification](../BeyondWaveform_Reproduction_Spec.md) transcribes the tables and distinguishes explicit statements from gaps. This project provides an **independent implementation of the stated method**; the paper does not identify enough artifacts or details to assert exact numerical reproduction.

## Source evidence and component contract

| Component | Implementation | Paper evidence | Selected artifact or choice |
|---|---|---|---|
| Encoder E | `models/feature.py:WavLMEncoder` | Frozen WavLM-Large, Eq.4 | [Pinned kNN-VC source](https://github.com/bshall/knn-vc), commit `c616845c4e309e24d5927f15adbdf277a3d65358`, with its WavLM-Large checkpoint; layer 6, 1024 dimensions, 16 kHz. Layer 6 is the compatible upstream vocoder's choice, **not identified in the attack paper**. |
| Vocoder V | `models/feature.py:FeatureVocoder` | Frozen HiFi-GAN, Eqs.2/7/15 | [Upstream regular WavLM-conditioned generator](https://github.com/bshall/knn-vc/blob/master/hubconf.py), release `g_02500000.pt`; it accepts `(batch,frames,1024)` and synthesizes `320*frames` samples. Native linear projection and residual architecture are upstream, not invented here. The prematched alternative is selectable; it is trained on kNN-prematched features and should be treated as a sensitivity experiment, not an identical reconstruction path. |
| Surrogate | `models/whisper.py:WhisperASR` | Raw Whisper-small for English; Mandarin dev fine-tuned version | [OpenAI Whisper](https://github.com/openai/whisper) native PyTorch model, multilingual `small`; loader verifies OpenAI's published SHA256 directory hash. This script uses teacher forcing and native differentiable log-Mel, freezing weights during attacks. |
| Target | `models/targets.py` | Whisper family and CTC targets | Raw Whisper checkpoints or independently pinned Hugging Face CTC snapshots; no target is imported during generation. Paper checkpoint revisions and decoder recipes are absent. |
| Quality | `evaluation.py:QualityScorer` | DNSMOS, NISQA, UTMOS | TorchMetrics 1.6.1 DNSMOS OVRL (non-personalized), NISQA MOS, [SpeechMOS UTMOS strong](https://github.com/tarepan/SpeechMOS/tree/v1.2.0). The paper's scorer versions/calibrations are absent. |

Upstream source is downloaded by `scripts/download_models.py`, pinned to the commit above, and kept under `artifacts/sources/`; checkpoints have SHA256 receipts. No source code is executed from an unpinned branch. The first clean/reconstruction comparison determines whether this chosen encoder/vocoder is usable for the study. We do not insert kNN feature replacement: Eq.2 adds a same-shaped tensor directly to the clean features. We also avoid the upstream `matcher.vocode()` inference wrapper because that wrapper disables input gradients.

The workstation examined during development had an NVIDIA TITAN RTX, not the paper's L20. Timings and memory claims from Appendix D cannot be inferred from this machine. The Docker dependency versions are engineering choices; the paper supplies none.

## Equation to code map

| Paper | Code and exact computation |
|---|---|
| Eqs.1,3 | `WhisperASR.transcribe`, `CTCASR.transcribe`, `error_counts`, and `aggregate_errors` decode saved audio, then compute corpus-level WER/CER. Target evaluation is after generation. |
| Eqs.2,4,5,7,8,15 | `feature_attack` caches detached `q=E(x)`, optimizes a single `delta` of exactly `(T,D)`, calls frozen `V(q+delta)`, and saves that waveform. No waveform residual is added. |
| Eq.6 | `project_relative_ball_` projects with global Frobenius/L2 norm onto `||delta||_F <= rho*(||q||_F+eps)`, after **every** update. The trace records the ratio. |
| Eqs.9,10 | `teacher_forcing_tokens` supplies Whisper's start/language/task/no-timestamps prefix; `lexical_nll` scores only ground-truth lexical tokens, omitting prefix and EOT. `feature_attack` minimizes **negative** NLL. |
| Eq.11 | `CleanReference` caches detached `TV(q)` and `HF(x)` from original clean input. Numerators are `TV(q+delta)` and `HF(V(q+delta))`; `lambda_perc` weights both, `alpha_hf` the HF ratio. |
| Eq.12 | `temporal_variation` takes squared adjacent frame differences, sums all feature coordinates, and averages over `T-1`. No feature-dimension mean. |
| Eq.13 | `high_frequency_fraction` sums STFT power above a **strict** `f>6000Hz` cutoff and divides by total STFT power, summed across time and bins. |
| Eq.14 | `feature_attack` runs 50 constrained updates by default; only `delta` is an optimizer parameter. |
| Eq.16 / Table 2 | `selection.py` accepts only surrogate evaluations from `role=validation` on identical utterances and protocol. All three average MOS scores must be strictly above 2.5, then the largest surrogate corpus WER/CER wins. |

For `rho=0`, the output is `V(q)`; it is **not** the original `x`. Every feature run saves `x`, `V(q)`, and `V(q+delta)` so reconstruction and optimization effects can be distinguished. The zero-delta and perceptual-only controls use the same path. Ablations remove the exact scalar terms in Eq.14.

## Declared choices and discrepancies

These details are absent from the paper and can change the reported numbers. Defaults are in `configs/english.yaml`, saved with each run:

| Choice | Default |
|---|---|
| Audio policy | Mono channel mean, 16 kHz polyphase resampling when needed, no VAD or loudness change, no normalization/clipping. Reject silence, nonfinite input, and >30 s rather than silently trim. Export IEEE 32-bit float WAV. |
| WavLM conditioning | Layer 6, no external normalization, native regular (not prematched) WavLM-conditioned HiFi-GAN. Verify WavLM checkpoint's `cfg.normalize` and zero-perturbation reconstruction before final runs. |
| Attack optimizer | Adam, learning rate 0.01, zero initialization, 50 steps, project after each step, final iterate. A normal start and SGD are implemented for sensitivity tests. The optimizer, rate, initialization, and iterate rule are **unspecified in the paper**. |
| Attack NLL | Per-lexical-token mean, English/Chinese native Whisper tokens, true teacher forcing, prefix conditioning, EOT excluded. Paper specifies lexical-only mask but not sum versus mean, prefix details, or EOS handling. |
| Perceptual constants | `alpha_hf=1`, `eps=1e-8`, `n_fft=1024`, Hann window, `hop=256`, `center=True`, frame energy summed across time. Only `fc=6000Hz` is paper-specified. Zero-energy HF is rejected. |
| Recognition | Deterministic temperature zero, beam size five, language forced; scoring uses NFKC/lowercase/punctuation-to-space and corpus edit counts. Text rules and decoder settings are absent from the paper. |
| Validation | Independently chosen 100-utterance dev-clean subset, seed 2026, if author IDs are unavailable. All candidates share the same subset and scorer. |
| English test | Independently chosen 999-utterance test-clean subset, seed 2026, because Appendix D states 999 but does not list IDs. Train-clean-100 is reserved for model training/preparation. |
| Mandarin training | Three epochs of native Whisper-small AdamW with gradient accumulation eight on AISHELL development data, plus a speaker-disjoint validation reserve. This is an **independent recipe**; paper gives no hyperparameters. Never fine-tune on held-out AISHELL test. |
| Waveform baselines | PGD, MI-FGSM, VMI-FGSM are labeled independent L∞ lexical-NLL adaptations. Table 2's selected epsilon/step/momentum/N/beta and 50 steps are available in `waveform_attack` and `experiments.py`. Paper omits the exact objective, norm, start and implementation recipe. |

The paper calls a defense **DE-AT** in prose and **DT-AT** in Table 1, with no checkpoint/training recipe; likewise CE-AT, DMW, TI, WaveGuard, AudioPure, PVP Vote, Muting Whisper, and SlothSpeech are insufficiently specified for faithful replication. An explicit `extension` target or attack adapter can integrate independently recovered implementations; no Table 1 label is silently assigned to a different algorithm. `lpf` is implemented only as a clearly labeled, configurable engineering example.
