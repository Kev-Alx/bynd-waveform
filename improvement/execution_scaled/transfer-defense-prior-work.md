# Scaling attack strength without giving up transfer or defense robustness

Research note, 22 October 2026, Asia/Taipei. Primary papers, author code and model cards checked during this continuation. This note proposes experiments; it reports no new attack results. All four frozen evaluation recognizers remain excluded from training and selection.

## Recommendation

The next substantial experiment should keep a speech-generative search space, use substantially longer optimization, and explicitly optimize several public surrogate/transform conditions. A larger decoder is a reasonable separate representation change, provided its clean reconstruction passes first. Increasing the capacity of the failed waveform generator without changing its training signal is poorly motivated by the current evidence.

The strongest immediately executable optimization baseline is the existing WavLM/HiFi-GAN feature attack with Whisper-small plus the local Whisper-large-v2, and an explicitly registered transform distribution. This uses models already present. Both recognizers are Whisper models, so their ensemble does **not** establish cross-architecture generalization. A distinct, non-reserved CTC training surrogate can be added subsequently: `facebook/data2vec-audio-base-960h`. Its official card specifies 16-kHz input and a public CTC implementation; its checkpoint, preprocessing and vocabulary would need to be acquired and pinned before use. This is added-surrogate access, track T2. [Official model card](https://huggingface.co/facebook/data2vec-audio-base-960h).

For a scalable learned method, train an **input-conditioned feature residual head from successful per-utterance feature teachers**, then fine-tune it on the existing disjoint 10-hour corpus with the same ensemble and transforms. This is an engineering proposal motivated by the previous near-identity failure, not a claimed published distillation recipe or a guaranteed improvement. Its first question is whether nonzero, useful teachers can be learned; its second is whether the amortized policy preserves the teachers' attack–quality frontier. Training more data before answering the first question wastes the newly authorized compute.

## What the closest prior work actually supports

### AudioShield is important, but is a different learned object

AudioShield learns a universal latent perturbation using a VITS autoencoder and target-feature adaptation, then transfers the resulting audio to unseen recognizers. Its reported protection success rate uses CER≥50%, rather than meaning “WER above 75%.” The paper's long-audio table reports NISQA 2.43; its countermeasure tables include values near 2.3–2.7. Those are not evidence of meeting our NISQA≥3.75 gate. Its evaluation also filters empty/“NA” commercial outputs; our registered complete-cohort analysis must retain such outputs and explicit failures. These differences prevent direct adoption of its numerical success rates as predictions for this project. [Paper, §§5.1, 5.6, 5.9 and Appendix B](https://arxiv.org/html/2504.00858v1).

The official training code initializes one trainable latent tensor from a target-text latent representation, adds it to random latent segments, adds Gaussian latent noise, and minimizes targeted DeepSpeech CTC plus 50 times a cosine penalty to the target latent. Adam receives a signed gradient; the universal tensor is clipped to `[-tau,tau]`. It uses three outer epochs and defaults to 5,000 inner iterations per selected batch. This is neither a newly trained large waveform generator nor untargeted reference-NLL ascent. Copying it would change the objective and reconstruction model, so it belongs in an explicit adapted baseline. [Author training code](https://github.com/WeifeiJin/AudioShield/blob/main/train.py).

The author artifact now has a public Zenodo record containing source, processed data, VITS and DeepSpeech pretrained models. This removes an assumed “no available checkpoint” objection, but does not prove a compatible local load or permit treating the authors' 500 training/2,000 test examples as our clean reserves. [Author artifact](https://zenodo.org/records/14711220).

There is also a rate-contract concern to investigate before an AudioShield comparison: `run_conversion_tensor` resamples input to 16 kHz, then creates a spectrogram using the class's 22,050-Hz model setting and finally downsamples decoded audio from 22,050 to 16,000 Hz. The apparent duration/frequency inconsistency is an observation about that path, not a demonstrated bug in every author experiment. An adaptation must bind the waveform rate seen by each operation and verify duration, clean WER and quality. [Author inference code](https://github.com/WeifeiJin/AudioShield/blob/main/inference.py).

### Much longer optimization and diverse surrogates have direct ASR precedent

Olivier, Abdullah and Raj combine two SSL ASR proxies, use 10,000 attack iterations, and use a third proxy for checkpoint selection. Their study finds that attack-time dropout/layer-drop can improve transfer despite weakening or slowing white-box optimization. This supports testing stronger optimization and model diversity rather than equating rapid source overfitting with transfer. It does not establish that 10,000 steps are necessary, or that arbitrary new dropout in Whisper reproduces their result. [Paper, §§3.1 and 4.3](https://arxiv.org/html/2209.13523v2).

Their published multi-model YAML optimizes HuBERT-large and wav2vec2-large with Data2Vec as the stopping proxy, and explicitly notes a two-GPU/32-GB execution context. Those first two checkpoints overlap our sealed evaluation definitions, so importing that configuration would invalidate this study. We may adapt the multi-source mechanism using different permitted proxies and sequential gradients. No target-dependent stopping is allowed. [Author configuration](https://github.com/RaphaelOlivier/asr_transferability/blob/master/attack_configs/cw_tgt_multi.yaml).

Momentum and normalized accumulated gradients already have extensive transfer-attack prior art; adding them is a strong baseline, not a new contribution. SAGO separately applies momentum-based attacks to differentiable audio front ends. [MI-FGSM paper](https://openaccess.thecvf.com/content_cvpr_2018/html/Dong_Boosting_Adversarial_Attacks_CVPR_2018_paper.html), [ASR/SAGO paper](https://arxiv.org/html/2411.09220v1).

### Transformation robustness must be part of the question

Expectation over transformation optimizes against a declared transformation distribution. It supports a mechanism for robustness to those transformations; it gives no general guarantee against transformations outside that distribution. Qin et al. supply direct ASR precedent for optimizing environmental robustness and separately assessing human imperceptibility through auditory masking. A local energy envelope or STFT loss is not their masking model. [EOT paper](https://proceedings.mlr.press/v80/athalye18b.html), [Qin et al.](https://proceedings.mlr.press/v97/qin19a.html).

## Concrete optimization experiment

These are proposed fixed choices to register before generation, rather than additional retrospective tuning of the completed pilots.

1. **Search space:** freeze the original compatible feature encoder/decoder for the first strong baseline, with the existing clean feature reference and relative radius 0.1. A new high-capacity decoder is a separate condition with its own reconstruction control. Keep original TV/HF penalties visible. Do not silently equate feature radius with waveform L-infinity or claim a larger model alone is the contribution.
2. **Public surrogates:** Whisper-small and local Whisper-large-v2, weights fixed before results. Keep Whisper-base, multilingual Whisper-medium, `facebook/wav2vec2-large-960h-lv60-self` and `facebook/hubert-large-ls960-ft` sealed. Data2Vec-base is an optional registered third training surrogate, not an evaluation target.
3. **Attack losses:** maximize ordinary lexical reference-transcript NLL, excluding special/EOT tokens as in the audited local adapter. Divide each model's sum NLL by its scored lexical-token count, then apply a fixed per-model calibration scale from the predeclared three duration-stratified development probes. Freeze those scales before outcomes. This gives a well-defined weighted objective instead of dynamically changing it to hide a weak model or transform.
4. **Transform expectation:** include identity at weight 1/2, a differentiable 6-kHz low-pass at 1/4, and a differentiable 16→8→16-kHz resampling transform at 1/4. Bind exact filter/taps/padding/length rules and input scaling. For the first reproducible run, compute the full three-condition expectation per update; do not call a deterministic single-filter attack stochastic EOT. If stochastic augmentation is later added, bind its distribution and seed. These weights are a proposed protocol, not literature-derived optimal values.
5. **Gradients and memory:** obtain each surrogate/transform gradient with respect to a detached waveform leaf and accumulate those waveform gradients. Then perform one vector–Jacobian product through the vocoder to the feature perturbation. This can be mathematically equivalent to the weighted sum without retaining all ASR graphs simultaneously. Models can be offloaded between fixed blocks; measure actual switching overhead. Test the accumulated gradient against a direct summed-graph gradient on a tiny example before long execution. Freeze model parameters, retain input gradients, and check finite nonzero gradients. Never run a reserved recognizer to test memory fit.
6. **Long trajectory:** save deterministic checkpoints at steps 50, 200 and 500. Use one registered learning-rate schedule, not repeated selection from new arbitrary step counts. Keep 500-step single-surrogate and ensemble-without-transforms controls: extra source backward calls and extra optimization time must be visible. A six-condition ensemble/EOT step is not equal in compute to one original step. Report model-specific backward counts, wall time and peak VRAM.
7. **Selection:** source-only mean WER over the permitted recognizers and transformations is a development score. Require every automatic quality floor, preserve the complete cohort, inspect insertions/deletions/empty transcripts, and freeze one checkpoint/operating point before larger validation. Score raw and each transformed view separately; a mean can conceal an easily defended condition. No optimizer should directly maximize a MOS predictor.

Per-step gradient normalization is an optional ablation, not a silent replacement: `g = mean(g_m / (mean(abs(g_m))+epsilon))` changes the effective objective weights at every step. If used, declare it, log the raw component norms and pairwise gradient cosines, and compare against the fixed-calibration weighted expectation. Momentum can then accumulate that declared direction. Avoid copying a conflict-projection method merely because gradients disagree: the completed constrained experiment already showed that rejecting most steps can leave WER unchanged.

## A larger learned policy that changes the failure mechanism

Use clean WavLM features as input and predict a same-shape perturbation. A practical candidate is a 512-channel temporal residual head with eight dilated GLU blocks, dilation pattern 1/2/4/8 repeated twice, LayerNorm and a final 1×1 projection back to the feature dimension. Verify its actual parameter count; roughly tens of millions is a design estimate, not a measurement. Apply the registered relative-radius projection to every emitted feature residual. This permits a larger policy without requiring an ASR-size network to generate sample-level noise.

Generate teachers only on training utterances, beginning with the existing disjoint one-hour subset. Use full teacher trajectories and fixed checkpoints from the strong per-example method above, retaining failures rather than selecting only convenient speakers. Train the head to predict those feature residuals, then use the existing 10-hour training manifest for adversarial ensemble/EOT fine-tuning. Decode whole utterances; random waveform crops cannot reuse full reference transcripts without alignment. Supervised latent regression needs no ASR graph, so it can establish nonzero teacher recovery cheaply before expensive fine-tuning.

Keep a teacher-distillation-only checkpoint and the same-sized adversarial-from-scratch head as mechanism controls. Record perturbation RMS/radius distributions, source loss, decoded WER and quality on full 48-point development evaluations at a fixed cadence. Zero outputs, merely nonzero outputs and successful attacks are three different states. Checkpoints must earn advancement through decoded performance and quality, not training loss alone. Teacher generation, extra data, training and final inference all count toward lifetime cost. Exact training duration should be frozen after measured per-update throughput; there is no defensible hour estimate yet for large-v2 on this single 24-GB GPU.

FAPG already uses a Wave-U-Net for input-dependent fast perturbation generation and introduces a universal variant. Its reported tasks are classification rather than full-sentence transcription, so it supports the architecture family and efficiency motivation, not an expected sentence-WER gain. AudioShield already establishes learned universal latent transfer. A learned feature head, teacher initialization, ensemble gradients and EOT require empirical justification; their combination alone is not a priority claim. [FAPG paper](https://arxiv.org/abs/2004.12261).

## What preserving “anti-defense ability” would mean

Publish three distinct results: raw unseen-ASR transfer; post-transform transfer on transformations used during optimization; and post-transform transfer on frozen transformations absent from optimization. The second measures adaptation to known transformations, while the third tests broader generalization. Include transformed clean and reconstructed controls, and post-defense quality. A defense that destroys clean speech cannot be credited as selectively removing the attack.

The local `beyondwaveform/defenses.py` implements author-policy WaveGuard resampling plus PCM16 I/O using librosa/resampy. A torchaudio differentiable resampler is a training approximation, not automatically the exact same transformation. Use the frozen true adapter at evaluation and report the mismatch. If PCM quantization is included in the adaptive training forward path, state the backward approximation explicitly; BPDA is established methodology, not an exact gradient or a new defense-evasion principle. [BPDA/gradient-obfuscation paper](https://proceedings.mlr.press/v80/athalye18a.html).

WaveGuard is a transcript-consistency **detector**, not merely down/up-sampling. Post-resampling WER alone cannot support a claim of bypassing the full detector. Detection evaluation needs the actual clean/attack score distributions, thresholds and AUC/operating points. [WaveGuard paper](https://www.usenix.org/conference/usenixsecurity21/presentation/hussain).

AudioPure's original public study evaluates speech-command recognition with diffusion purification; extending it to whole-sentence ASR requires explicit checkpoint/rate/length contracts. Its presence in a source tree does not establish an executed or fair sentence defense. Add diffusion/codec/learned defenses only with runnable frozen recipes and clean-utility checks. [AudioPure paper](https://arxiv.org/abs/2303.01507).

An observed source WER above 75% would be a useful intermediate result. The requested improvement needs that strength at the quality gate, frozen unseen-ASR transfer comparisons, actual defense evaluation, and human-content evidence. None of the current methods has supplied that combination. The new authorization allows a more consequential experiment; it does not change what must be measured.
